## 📋 Шаг 3: Настройка Frontend для локального backend

### 3.1 Создайте файл `.env.local` в папке `frontend`

**ВАЖНО:** Файл `.env.local` не попадает в git, создайте его вручную!

```powershell

```

Создайте файл `.env.local` (без расширения, точка в начале обязательна!) со следующим содержимым:


**Подробная инструкция:** См. `frontend/ENV_LOCAL_SETUP.md`

## 🔧 Решение проблем

### Проблема: Порт 8001 тоже занят

**Решение:** Измените порт в `backend/run_local.py`:

```python
uvicorn.run(
    "app.main:app",
    host="127.0.0.1",
    port=8002,  # Измените на любой свободный порт
    reload=True,
    log_level="info"
)
```

И обновите `frontend/.env.local`:
```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8002/api/v1
```

### Проблема: База данных не создается

**Решение:** Убедитесь, что backend запущен хотя бы один раз. База данных создается автоматически при первом запуске.

### Проблема: Frontend не подключается к backend (CORS ошибка)

**Решение:** 
1. Проверьте, что backend запущен на порту 8001
2. **Убедитесь, что файл `frontend/.env.local` создан** и содержит:
   ```env
   NEXT_PUBLIC_API_URL=http://127.0.0.1:8001/api/v1
   ```
3. **Перезапустите frontend** после создания/изменения `.env.local` (остановите Ctrl+C и запустите снова)
4. Проверьте в консоли браузера (F12) - должно быть: `API Base URL: http://127.0.0.1:8001/api/v1`
5. Если видите другой URL - очистите кэш: `rm -r frontend/.next` и перезапустите

**Подробнее:** См. `frontend/ENV_LOCAL_SETUP.md`
