# 🧪 СОЗДАНИЕ ТЕСТОВОГО ПОЛЬЗОВАТЕЛЯ

## Быстрый запуск

```powershell
# Перейдите в папку backend
cd backend

# Запустите скрипт создания тестового пользователя
python create_test_user.py
```

## Что делает скрипт:

1. ✅ Создает пользователя `test@test.com` с паролем `Test1234`
2. ✅ Устанавливает баланс **100 кредитов**
3. ✅ Создает лицензионный ключ для расширения
4. ✅ Верифицирует email (не нужно подтверждать)

## Данные для входа:

После запуска скрипта вы получите:
- **Email:** `test@test.com`
- **Password:** `Test1234`
- **Balance:** 100 кредитов
- **License Key:** (будет показан в консоли)

## Вход в личный кабинет:

1. Откройте: http://localhost:3000/login
2. Введите email и пароль
3. Нажмите "Войти"

## Тестирование расширения:

1. **Установите расширение:**
   - Откройте Chrome: `chrome://extensions/`
   - Включите "Режим разработчика"
   - Нажмите "Загрузить распакованное расширение"
   - Выберите папку: `extension/dist/`

2. **Авторизуйтесь в расширении:**
   - Откройте расширение (иконка в панели Chrome)
   - Вставьте **License Key** (из вывода скрипта)
   - Нажмите "Авторизоваться"

3. **Протестируйте:**
   - Откройте Discord в браузере
   - Перейдите в канал Midjourney
   - Используйте расширение для отправки промптов

## Если пользователь уже существует:

Скрипт автоматически:
- Обновит баланс до 100 кредитов
- Проверит/создаст лицензионный ключ
- Покажет актуальные данные для входа
