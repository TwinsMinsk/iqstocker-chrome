# Исправление: Страница рефералов возвращает 404

**Дата:** 30.12.2025  
**Проблема:** Страница `/dashboard/referral` показывает "Не удалось загрузить статистику" с ошибкой 404

---

## 🔍 Причина

1. **У старых пользователей нет `referral_code`** - пользователи, созданные до добавления реферальной системы, не имеют кода
2. **Backend не генерировал код автоматически** - эндпоинт `/users/me/referral` не проверял наличие кода

---

## ✅ Исправления

### Backend (1 файл)

**`backend/app/api/v1/endpoints/users.py`**

Добавлена автоматическая генерация `referral_code` если его нет:

```python
@router.get("/me/referral", response_model=ReferralStatsResponse)
async def get_my_referral_stats(...):
    # Убеждаемся что у пользователя есть referral_code (для старых пользователей)
    if not user.referral_code:
        referral_service.assign_referral_code(db, user)
        db.refresh(user)
    
    stats = referral_service.get_referral_stats(db, str(user.id))
    return ReferralStatsResponse(**stats)
```

**Результат:** Теперь при запросе статистики код генерируется автоматически если отсутствует.

---

### Frontend (1 файл)

**`frontend/app/dashboard/referral/page.tsx`**

1. **Улучшена обработка ошибок:**
   - Добавлены специфичные сообщения для 404 и 401
   - Автоматический редирект на логин при 401

2. **Обработка отсутствующего referral_code:**
   - Если код отсутствует, показывается сообщение "Реферальный код генерируется..."
   - Кнопка "Обновить" для повторного запроса

**Результат:** Пользователь видит понятное сообщение вместо ошибки.

---

### Миграция (новый скрипт)

**`backend/scripts/assign_referral_codes_to_existing_users.py`**

Скрипт для массового назначения кодов существующим пользователям:

```bash
cd backend
poetry run python scripts/assign_referral_codes_to_existing_users.py
```

**Результат:** Все существующие пользователи получат referral_code.
